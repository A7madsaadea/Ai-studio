# Tech3arabi AI Studio — استوديو تك عربي للصور والفيديو 🎬📸

منصة ويب عربية مبنية باستخدام **Python وFlask** لإدارة ومعالجة الصور، وفرز الوسائط، وتجهيز فيديوهات قصيرة من الصور والمقاطع. صُممت لتختصر الأعمال المتكررة في صناعة المحتوى: من رفع مجموعة ملفات، إلى تحسينها ومراجعتها، ثم تنزيلها أو حفظها ضمن مجلدات منظمة.

> **ملاحظة عن الخصوصية:** معالجة الصور الأساسية تتم محلياً على الخادم الذي يشغّل التطبيق. لكن رفع النتائج إلى Google Drive يرسل الملفات إلى Google، ومسار تحليل الفيديو `/analyze-video` يرسل الصوت/الفيديو إلى AssemblyAI، كما قد تُنزّل ميزات AI Edit وMusicGen أوزان نماذج من مستودعات خارجية عند أول استخدام إذا لم تكن مخزنة محلياً.

---

## ماذا يقدم المشروع؟

### 1. معالجة الصور وفرزها

من صفحة **معالج الوسائط** (`/processor`) يمكن رفع عدة صور أو مقاطع فيديو والعمل عليها ضمن جلسة واحدة. تتضمن خيارات المعالجة:

- تحسين الإضاءة تلقائياً.
- موازنة اللون الأبيض لتقليل الميل اللوني.
- تقليل التشويش، خصوصاً في الصور منخفضة الإضاءة.
- تعديل ميل الأفق عند اكتشافه.
- قصّ يركز على الوجه المكتشف، مع قص مركزي بديل إذا لم يُكتشف وجه.
- قلب الصورة أفقياً أو عمودياً.
- إضافة شعار تك عربي عند تفعيل خيار العلامة المائية.
- تصنيف الوسائط العمودية ذات النسبة القريبة من **9:16** ضمن `REELS`، وبقية الوسائط ضمن `PHOTOS`.
- معاينة النتائج، اختيار الملفات المقبولة، ثم تنزيلها كملف ZIP أو حفظها ضمن مجموعة/حدث.

يدعم هذا المسار صور `JPG` و`PNG` وفيديوهات `MP4` و`MOV`. اكتشاف الوجه الحالي يعتمد على Haar Cascade من OpenCV، وليس على `face-alignment`.

### 2. فلترة الصور وتحسينها

من مسار رفع الصور يمكن إرسال عدة صور دفعة واحدة ليقوم التطبيق بـ:

- اكتشاف الصور المهزوزة أو الخارجة عن التركيز.
- اكتشاف الصور المتشابهة أو المكررة باستخدام perceptual hashing.
- تحسين الصور المقبولة وإضافة الشعار إليها.
- عرض النتائج للمراجعة، وتنزيل صورة منفردة أو جميع النتائج بصيغة ZIP.

### 3. صنع الفيديو

تتيح صفحة الفيديو (`/video`) مسارات عمل تعتمد على فيديو مرجعي ووسائطك:

- تحليل الفيديو المرجعي إلى مشاهد واستخراج صور مصغرة ومعلومات مثل المدة والأبعاد ومعدل الإطارات.
- مطابقة الصور أو المقاطع المرفوعة مع المشاهد باستخدام CLIP عند توفر النموذج.
- تجميع الوسائط في فيديو نهائي.
- المسار البرمجي `/video/assemble` يقبل إعدادات انتقالات ومقاطع افتتاحية وختامية، لكن هذه الخيارات غير متاحة في واجهة المراجعة الحالية، ويعتمد تطبيقها على MoviePy.
- وضع **AI Edit** لتجميع صور ومقاطع متعددة بما يتماشى مع بنية الفيديو المرجعي. التحليل الأعمق يعتمد على Qwen2-VL، وقد يتطلب تنزيل أوزان النموذج واعتماديات إضافية؛ ويتوفر تحليل أبسط عند تعذر ذلك.
- تجهيز الفيديو للمعاينة والتنزيل.

يستخدم اكتشاف المشاهد PySceneDetect عند توفره، مع مسار بديل يعتمد على OpenCV. بعض إمكانات المطابقة أو معالجة الصوت وتوليد الموسيقى اختيارية وتعتمد على تثبيت النماذج والأدوات المناسبة؛ راجع قسم المتطلبات.

### 4. صفحات المحتوى

يتضمن التطبيق صفحات للسكريبتات (`/script`)، و**Style Brain** (`/brain`)، والأفكار (`/ideas`)، وتحليل الفيديو (`/analyze`). وهي توفر واجهات المشروع المرتبطة بإعداد المحتوى. يمر تحليل الفيديو في المسار الحالي عبر خدمة AssemblyAI الخارجية، لذا لا ترفع إليه محتوى حساساً قبل مراجعة إعدادات الخصوصية والخدمة.

## الفوائد

- **تقليل العمل اليدوي:** معالجة وفرز عدد من الملفات من خلال واجهة واحدة.
- **نتائج منظمة:** حفظ الصور والفيديوهات ضمن فئات مثل `REELS` و`PHOTOS`.
- **مراجعة قبل الاعتماد:** معاينة الملفات واختيار المقبول منها قبل التنزيل أو الحفظ.
- **تجهيز أسرع للنشر:** تحسين الصور وإضافة العلامة المائية وتجميع النتائج في ZIP.
- **سير عمل مرن:** يمكن استخدام معالجة الصور دون تفعيل تكامل Google Drive أو مكونات الذكاء الاصطناعي الاختيارية.
- **واجهة عربية:** صفحات المشروع الأساسية مصممة للاستخدام باللغة العربية.

## المتطلبات

- Python 3.
- تثبيت الحزم الأساسية من `requirements.txt`.
- FFmpeg متاح في `PATH` عند استخدام وظائف الفيديو التي تعتمد عليه.
- مساحة تخزين كافية للملفات المؤقتة والنتائج؛ الحد الأقصى للطلب مضبوط حالياً على 500 MB في التطبيق.

الاعتماديات الأساسية تشمل Flask وPillow وOpenCV وImageHash. أما مكونات مثل PySceneDetect وMoviePy وOpenCLIP/PyTorch وDemucs وTransformers وموديل Qwen2-VL فليست كلها مدرجة في `requirements.txt` الحالي، وقد تحتاج إلى تثبيت منفصل وإعداد مناسب. يتطلب MusicGen إعداد CUDA في الشيفرة الحالية. إذا لم تتوفر بعض المكونات الاختيارية فقد تعمل بدائل محدودة أو تتعطل الميزة المعتمدة عليها. قد تتصل مكونات النماذج بمستودعات خارجية لتنزيل الأوزان ما لم تكن مخزنة محلياً.

## التشغيل محلياً

من مجلد المشروع:

```bash
python -m venv .venv
```

فعّل البيئة الافتراضية:

```powershell
# Windows PowerShell
.venv\Scripts\Activate.ps1
```

```bash
# macOS / Linux
source .venv/bin/activate
```

ثم ثبّت الاعتماديات الأساسية وشغّل التطبيق:

```bash
python -m pip install -r requirements.txt
python app.py
```

افتح العنوان الذي يظهر في الطرفية؛ الإعداد الافتراضي في التطبيق هو:

```text
http://localhost:8080
```

> قد تحتاج إلى تثبيت FFmpeg وبعض الاعتماديات الاختيارية يدوياً لتشغيل وظائف الفيديو المتقدمة. كما أن `scenedetect` اسم الاستيراد البرمجي لحزمة PySceneDetect؛ عدم تثبيتها لا يمنع مسار كشف المشاهد البديل المعتمد على OpenCV من المحاولة.

## إعداد Google Drive (اختياري)

لتفعيل رفع الصور المعالجة إلى Google Drive:

1. أنشئ Service Account من [Google Cloud Console](https://console.cloud.google.com/).
2. فعّل Google Drive API وأنشئ ملف بيانات الاعتماد JSON.
3. حوّل ملف الاعتماد إلى Base64، ثم خزّن الناتج في متغير البيئة `GOOGLE_CREDENTIALS_B64`.
4. لا ترفع ملف الاعتماد أو قيمة المتغير إلى GitHub، ولا تضع الأسرار داخل الشيفرة.

```bash
# Linux / macOS
base64 -i credentials.json | tr -d '\n'
```

في PowerShell يمكن استخدام:

```powershell
[Convert]::ToBase64String([IO.File]::ReadAllBytes('credentials.json'))
```

الرفع اختياري، ويتطلب مكتبات Google الموجودة في `requirements.txt` وإعداد بيانات الاعتماد. يمنح التطبيق صلاحية القراءة لأي شخص لديه رابط المجلد المنشأ؛ لذلك يمكن لحاملي الرابط الوصول إلى الملفات. لا ترفع ملفات سرية، وراجع صلاحيات المجلد قبل مشاركة رابطه.

## تحليل الفيديو الخارجي (اختياري)

المسار `/analyze-video` يرسل الفيديو إلى AssemblyAI عبر الإنترنت، ويتطلب ضبط `ASSEMBLYAI_KEY` كمتغير بيئة. لا يستخدم التطبيق مفتاحاً افتراضياً؛ لذلك يتوقف المسار برسالة خطأ عند غياب المفتاح. لا تستخدمه مع ملفات حساسة إلا بعد الموافقة على إرسالها إلى الخدمة.

## النشر

يحتوي المستودع على `Dockerfile` و`railway.toml` لدعم إعدادات الحاويات والنشر على Railway. قبل النشر:

- اضبط متغيرات البيئة والأسرار في منصة الاستضافة، لا في الشيفرة.
- تأكد من توفر FFmpeg إذا كانت ميزات الفيديو مطلوبة.
- راجع حدود حجم الرفع ومساحة التخزين والملفات المؤقتة.
- تحقق من إعدادات الوصول إلى نتائج Google Drive.
- اختبر الميزات الاختيارية بعد تثبيت اعتمادياتها على بيئة النشر.

## التقنيات المستخدمة

- **Python وFlask:** تشغيل التطبيق ومسارات الويب.
- **OpenCV:** تحليل الصور والفيديو، كشف الاهتزاز، وتقنيات المعالجة.
- **Pillow:** فتح الصور وتعديلها وحفظها.
- **ImageHash:** مقارنة الصور لاكتشاف التشابه والتكرار.
- **FFmpeg:** أدوات مساعدة لاستخراج معلومات الفيديو ومعالجته وتجميعه.
- **PySceneDetect وCLIP وMoviePy وDemucs وMusicGen:** مكونات اختيارية لميزات تحليل الفيديو والمطابقة والصوت.

## حدود مهمة

- معالجة الصور الأساسية محلية، لكن Google Drive وAssemblyAI خدمات خارجية عند تفعيلها.
- خيارات الذكاء الاصطناعي للفيديو ليست جاهزة بمجرد تثبيت `requirements.txt`؛ تحقق من تثبيت كل اعتماد إضافي ومتطلبات الجهاز.
- قصّ الوجه الحالي يعتمد على Haar Cascade، وميزة التصنيف تعتمد على أبعاد الصورة/الفيديو؛ لا تستخدم نموذجاً لفهم محتوى الصورة.
- قد تختلف النتائج حسب جودة الملف والإضاءة والعتبات البرمجية، لذلك راجع النتائج قبل استخدامها.
- تحليل الفيديو في المسار الحالي عبر خدمة AssemblyAI الخارجية، لذا لا ترفع إليه محتوى حساساً قبل مراجعة إعدادات الخصوصية والخدمة.
